# GO HIGH

GO HIGH is a small game which is only keyboard controlled  game 
where the goal is to keep moving upward by jumping from platform to platform.

## How to Play

* Use the Left Arrow and Right Arrow keys to move.....
* Keep landing on platforms and try to go as high as possible.
* Your score increases as you climb....
* If you fall... the game ends and you have to start again

## Features

* it is only played by keyboard
* theres score counter too
* and when you lose, there is pop up of game over
* Simple background 

## Built With

* HTML
* CSS
* JavaScript


## Controls
ARROW LEFT - LEFT
ARROW RIGHT - RIGHT
